## Использование приложения

Правообладатель предоставляет пользователю бесплатное неисключительное разрешение скачать оригинальный подписанный APK из официального выпуска, установить его на совместимое устройство и использовать приложение по назначению. Добровольная поддержка проекта не является условием разрешения. Условия сторонних сервисов, включая Google Flow, применяются отдельно.

Собственный код и материалы Flow Bridge остаются закрытыми. Публикация APK не предоставляет разрешения на получение или распространение собственных исходников. Для передачи приложения другим пользователям можно использовать ссылку на официальный выпуск. Зеркалирование оригинального APK и распространение изменённых сборок допускаются только по отдельному разрешению правообладателя в пределах его прав.
