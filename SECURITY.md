# Безопасность

Этот комплект идентифицирует только 0.3.0 (build 9). Политика сроков поддержки и исправлений пока не установлена.

Проверяйте SHA256 и подпись по INSTALL_RU.md. Несовпадение — основание остановить установку. Не доверяйте одному имени APK или versionName.

Для уязвимости не создавайте публичный Issue с деталями эксплуатации. Если в новом репозитории включён GitHub Private Vulnerability Reporting, используйте Security → Report a vulnerability. Включение и доступность этого канала пока BLOCKED. До этого через канал проекта https://t.me/ITHRONIC запросите приватный способ связи, без отправки деталей в публичные комментарии. Проверенного приватного адреса сейчас нет.

В первом обращении достаточно версии, общей категории проблемы и безопасного способа связи. Не передавайте cookies, токены, пароли, данные аккаунта или чувствительные логи. Срок ответа не обещается.
