# Flow Bridge Android

[English](README.en.md)

Коммерческое стороннее Android-приложение для работы с Google Flow через встроенный браузер GeckoView. Этот репозиторий предназначен для распространения готового приложения и документации. Исходный код приложения здесь не распространяется.

**Статус: приватная подготовка выпуска. Draft v0.3.0 создан; публичная публикация ещё не одобрена.** Выбран новый distribution-репозиторий [jcmir/flow-bridge-android-releases](https://github.com/jcmir/flow-bridge-android-releases), подготовка ведётся приватно.

## Возможности

- Работа с Google Flow во встроенном браузере.
- Переключение локальных профилей.
- Выбор файлов через системный Android picker для загрузки на сайт.
- Сохранение поддерживаемых фото и видео через механизм загрузки приложения.

Поддержка конкретного формата и успешная обработка файлов зависят также от сайта. Выбор файла не означает завершение серверной загрузки.

## Требования и совместимость

Android 8.0+ (API 26), **arm64-v8a**. Версия 0.3.0, build 9; пакет `local.flowbridge.android`; GeckoView 157. Нет сборки для 32-битных ARM и x86.

По сообщению владельца сборка проверена на двух смартфонах Realme. Это не подтверждает совместимость со всеми моделями Realme, Huawei, Xiaomi, Samsung или других производителей. Подробнее: [совместимость](COMPATIBILITY_RU.md).

## Скачивание и установка

После одобрения публикации официальный APK будет приложен к [GitHub Releases](https://github.com/jcmir/flow-bridge-android-releases/releases) вместе с `SHA256SUMS.txt`. До появления проверенной публичной ссылки этот документ не является объявлением доступного релиза. Архивы GitHub «Source code» не содержат APK.

Подтверждённый в локальных материалах канал проекта: [Telegram ITHRONIC](https://t.me/ITHRONIC). Наличие именно build 9 в канале отдельно не подтверждено.

Скачайте `FlowBridge-Android-0.3.0.apk`, проверьте хеш и сертификат по [инструкции](INSTALL_RU.md), разрешите установку для выбранного приложения-источника и откройте APK. Официальные сборки с тем же пакетом и сертификатом обновляйте без удаления приложения. После установки отключите разрешение установки из этого источника.
